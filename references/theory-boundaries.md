# 理论边界与结果解释

## 模型范围

本 Skill 将每个光学组视为理想薄透镜，用组等效焦距和组主平面间距描述系统。计算内容属于高斯光学和 ABCD 矩阵层面，适合建立变焦架构、初始焦距分配和运动关系。

三组模型包含前固定组 G1、变倍组 G2 和补偿组 G3。四组模型再增加后固定组 G4。`d12`、`d23`、`d34` 分别表示相邻组主平面间距，不是镜片边缘间机械空气隙。

## 通过条件

- 判别式 `D>=0`：补偿组倍率存在实数解。
- `d12/d23/d34>0`：当前理想主平面次序下不存在组间穿越。
- 像面漂移接近 0：长短焦运动满足一阶像面补偿关系。
- ABCD 焦距残差接近 0：矩阵计算与倍率乘积焦距关系一致。
- 终端倍率接近目标：实际计算端点达到所需变焦比。

“一阶通过”只表示上述模型内的必要条件通过。

## M3 与四组求解

`m3_middle=-1` 对应本程序采用的中间构型重根换支条件。程序在重根前后切换数学根，以连接长焦和短焦端。它是一个具体一阶构造方法，不是所有四组变焦镜头的普遍规定。

当 `m3_middle` 取其他负值时，单支连续求解会固定跟踪同一根分支。改变 M3 会同时改变推导出的 G1/G3/G4 焦距、变倍组总行程、补偿组位移、最小间距和系统总长，因此不能只根据最终倍率选择 M3。

M3 扫描会保留有效与无解候选。优先比较：

1. 是否一阶通过；
2. 最小组间距；
3. 变倍组和补偿组行程；
4. 最大组间总长；
5. 是否满足后续机械与像差设计的余量。

## 不包含的验证

本 Skill 不计算或保证以下内容：

- 单片曲率、厚度、材料和真实主平面位置；
- 球差、彗差、像散、场曲、畸变、色差、MTF 和波前；
- 光阑、入瞳、F 数、渐晕、视场和远心性；
- 镜片口径、机械碰撞、变焦凸轮可实现性；
- 温度、公差、装调、材料供应和可制造性。

完成一阶布局后，应将组焦距与间距作为详细光学设计的初始约束，再进行实际镜组展开、像差优化和机械校核。
